This folder is used when USE_SAMPLE_MEDIA=true (the default).

Name files exactly like your Google Drive catalog:

- `1.jpg` Product ID 1
- `4.mp4` Product ID 4
- `4.jpg` and `4.mp4` both belong to Product ID 4

Supported: jpg, jpeg, png, webp, mp4, mov.

`scripts/generate_samples.py` recreates the mock files used for the first dry run.
